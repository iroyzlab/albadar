## Petunjuk Teknis Penggantian dalam Kode HTML

Setelah menyimpan foto asli di folder rekomendasi (misal `assets/img/fasilitas/masjid.jpg`), perbarui atribut `src` pada berkas HTML terkait:
```html
<!-- Sebelum (Sampel Eksternal) -->
<img src="https://images.unsplash.com/photo-..." alt="Descriptive Alt Text" loading="lazy">

<!-- Sesudah (Foto Asli Sekolah) -->
<img src="assets/img/fasilitas/masjid.jpg" alt="Descriptive Alt Text" loading="lazy">
```
